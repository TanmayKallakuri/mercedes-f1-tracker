# Mercedes F1 Tracker

Static tracker for the Mercedes-AMG Petronas F1 Team's 2026 season: constructors' and drivers' standings, title math, cumulative points race against Ferrari and McLaren, race-by-race results, Antonelli vs Russell head-to-head, and the remaining calendar.

Single-file site (`index.html`), no build step. Deploys on Vercel as a static site.

Data compiled after Round 17 (Singapore GP, 11 Oct 2026) from formula1.com, F1-Fansite and GPFans.
